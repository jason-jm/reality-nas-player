# Product screenshots for PICO Space Pro
These plates use PICO OS 6 emulator captures of Reality NAS Player and a fictional library. The film covers and stills were created for this project.
| Feature | What is shown |
| --- | --- |
| [Nas matching](features/en/01-nas-matching.webp) | Movies and feature documentaries matched by folder, filename and year, with NFO, season and anime matching examples |
| [Nas connections](features/en/02-nas-connections.webp) | The Add a source screen with shared folders, DLNA and media servers |
| [Poster wall](features/en/03-poster-wall.webp) | The complete headset poster wall with two rows of films, categories and filters |
| [Video formats](features/en/04-video-formats.webp) | Video file extensions and unencrypted Blu-ray and DVD backup formats |
| [Subtitles audio](features/en/05-subtitles-audio.webp) | Text and picture subtitles, soundtrack selection and playback controls |
| [Vr cinemas](features/en/06-vr-cinemas.webp) | Space Lounge, Private Cinema, Village Square and Desert Camp as seen from the viewer’s seat |
| [Panoramic video](features/en/07-panoramic-video.webp) | 180° and 360° video with selectable projection and stereo layout |

On the demonstration WebDAV share, the headset read the eight titles, artwork and synopses from Kodi NFO files and images stored beside the videos. The filename and title detail shown in the matching example come from that scan. Each interface screenshot is placed at its original aspect ratio. The demo films are supplied separately from the player.
